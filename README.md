What was the problem you were solving in the projects for this course?
The task was to create a course planner that allows the user to store, search, and print courses. 
Project One allowed me to figure out which data structure best fit the program. Project Two was where the implementation occured.

How did you approach the problem? Consider why data structures are important to understand.
I compared data structures against each other to see the difference in their performance and efficiency. Data structures are important to understand as it allows us to speed up and make programs more efficient.

How did you overcome any roadblocks you encountered while going through the activities or project?
The main challenge I encountered was the implementation of the data structure. I tested the program periodically which led me to reviewing code and fixing mistakes.

How has your work on this project expanded your approach to designing software and developing programs?
Working on this project allowed me to understand why planning out a program is important before implementing it. When you plan out a program and choose a data structure that fits the program, it has a big effect on the efficiency of the program. 

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
Working on this project has given me more practice on how I organize my code. It also taught me that simple code can be better than detailed code as maintainability, readability, and adaptability are very important as programs become larger.
